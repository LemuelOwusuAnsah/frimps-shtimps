# Frimps Shtimps

A proper Belvedere pub site. Cold pints, warm welcomes.

## Stack
- Svelte 5 + Vite
- svelte-routing for pages
- Plain CSS, orange & white theme
- Unsplash imagery

## Commands

npm install
npm run dev
npm run build
npm run preview

## Pages

/           home
/menu       full menu
/story      our story
/visit      find us and booking form
