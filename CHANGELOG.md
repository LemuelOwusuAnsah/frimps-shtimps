# Changelog

## [0.4.0] - 2026-10-13

### Added

- GitHub Actions workflow to auto-deploy to GitHub Pages

### Added
- Initial Svelte 5 + Vite project
- Hash-based router with Home, Menu, Story, Visit, and 404 pages

- Hamburger menu for mobile
